Why this build
--------------
It is the last GeoLite2-City release MaxMind published under CC BY-SA 4.0. Since
30 December 2019 MaxMind only distributes GeoLite databases to registered accounts
authenticated with a licence key, under the GeoLite End User License Agreement
(https://www.maxmind.com/en/geolite2/eula). That agreement requires every user to
stop using and destroy each database within 30 days of the next release (twice a
week at the time of writing) and to impose the same duties on anyone the database
is shared with, so a newer build can neither be bundled with this project nor
downloaded without a MaxMind account. The CC BY-SA 4.0 licence of this build
is perpetual and irrevocable (sections 2(a)(1) and 6(c)), so it may keep being
used and redistributed with its notices intact. Updating the PHP reader library
does not change the location data.

Installing or restoring it
--------------------------
No MaxMind account, licence key or other credential is needed. From the project
root:

    bash _tools/pH7.sh
    install geoip db

Leave the prompt empty to use the bundled build. The command checks the installed
file against the checksum above, restores the tracked copy from Git when it is
available, and otherwise downloads the same 24 December 2019 archive from the
Internet Archive's capture of MaxMind's former public download URL, verifying its
checksum before installing it together with MaxMind's notice files.

Release packages omit the _tools/ directory. Restore a release installation's
GeoIP files from that same package rather than mixing database builds and
notices. Packages from 19.3.0 onward contain the 24 December build and the
notice files described here; earlier 19.x packages contain the older 3 December
2019 database. In a source checkout, restore GeoLite2-City.mmdb, LICENSE.txt,
COPYRIGHT.txt and README.txt together with the command above.

Entering a path instead installs a GeoLite2-City .mmdb or .tar.gz you obtained
yourself. Except for the exact bundled checksum, imports require PHP and the
Composer dependencies (run composer install first). Validation checks the
database type and sample IPv4/IPv6 lookups; it is not a full integrity scan.
Obtain custom files directly from MaxMind and verify their published checksum.
Archives must contain exactly one GeoLite2-City.mmdb and its LICENSE.txt,
COPYRIGHT.txt and README.txt files. Files are staged before replacement; a failed
install restores the previous files. If restoration itself fails, the command
reports the retained backup directory for manual recovery.

A GeoLite database built on or after 30 December 2019 is governed by
MaxMind's GeoLite EULA, not by CC BY-SA 4.0: keep MaxMind's attribution and the
notices shipped with it, replace it within 30 days of each MaxMind release, and
never commit it to this repository or redistribute it with the project.

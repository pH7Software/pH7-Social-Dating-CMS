# 📦 pH7Compress

## 🔭 Summary

**pH7Compress** is pH7Framework's content minification package. It compacts PHP, HTML, CSS, and JavaScript, and can enable zlib output compression.

It includes built-in CSS and JavaScript minifiers, with optional YUI Compressor and Google Closure service support.

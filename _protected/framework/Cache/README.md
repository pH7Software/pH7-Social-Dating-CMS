# ⚡ pH7Cache

## 🔭 Summary

**pH7Cache** is pH7Framework's lightweight, file-based caching package. It stores serialized data in groups and supports configurable lifetimes, custom cache locations, and clearing individual entries or groups.

An APC adapter is also included. The Memcache and Redis adapters are currently placeholders.
